# Scoop更新机制

Scoop 的更新机制是“只增不减”。

Scoop 在更新一个软件时，默认不会删除旧版本，
而是把新版本和旧版本同时保留在 apps 目录下，以支持你随时回滚。

可以用一个简单的比喻来理解：cleanup 是扔掉旧家具（占地方的旧程序本体），cache rm 是扔掉包装盒（安装时用的压缩包）。
两者都不影响你正在使用的家具（当前版本）。

```bash
scoop cleanup <xxx>  # 删除该软件所有旧版本的程序文件夹，只保留当前正在用的版本。
scoop cache rm <xxx>  # 删除该软件所有历史版本的安装包/压缩包缓存，不碰任何已安装的程序。

scoop cleanup -a -k  # 同时删除安装包/旧版本程序。好用，爱用，多用
```

> `cleanup`是扔掉旧家具（占地方的旧程序本体），
> `cache rm`是扔掉包装盒（安装时用的压缩包）。
> 两者都不影响你正在使用的家具（当前版本）。
