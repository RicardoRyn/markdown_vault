# 错误处理

### 用Result来处理可恢复的错误

可以在返回`Result`的函数中对`Result`使用`?`运算符，
可以在返回`Option`的函数中对`Option`使用`?`运算符，
**但是不可以混合搭配**。

在这些情况下，可以使用类似`Result`的`ok`方法或者`Option`的`ok_or`方法来显式转换。

`main`函数可以返回的类型是有限制的。
但是其也可以返回`Result<(), E>`

```rust
use std::error::Error;
use std::fs::File;

fn main() -> Result<(), Box<dyn Error>> {
    let greeting_file = File::open("hello.txt")?;

    Ok(())
}
```
