------------------------------------------------------------------------
本程序用于将测量的 3D+时间 数据集与指定的输入刺激时间序列进行反卷积。该程序也可以使用多个输入刺激时间序列进行多元线性回归。输出包括一个 AFNI `bucket` 类型数据集，其中对每个体素包含：

 * 线性回归系数的最小二乘估计
 * 系数显著性的 t 统计量
 * 单个输入刺激显著性的偏 F 统计量
 * 整体回归模型显著性的 F 统计量

程序还可以可选地输出额外数据集，包含：

 * 估计的脉冲响应函数
 * 拟合模型和误差（残差）时间序列

------------------------------------------------------------------------
* 程序 `3dDeconvolve` 执行普通最小二乘（OLSQ）回归。
* 程序 `3dREMLfit` 可用于执行广义最小二乘（GLSQ）回归，
  也称为“预白化”最小二乘，并结合对 ARMA(1,1) 时间相关结构的
  REML 估计：
   https://afni.nimh.nih.gov/pub/dist/doc/program_help/3dREMLfit.html
* `3dREMLfit` 的输入是 `3dDeconvolve` 输出的 `.xmat.1D` 矩阵文件，
  `3dDeconvolve` 还会把一个 `3dREMLfit` 命令行写入文件，
  使后者更容易使用。
* `3dREMLfit` 还允许体素特异性回归量，而 `3dDeconvolve` 不允许。
  例如，这一特性与 `afni_proc.py` 的 `-fanaticor` 选项一起使用。
* 非线性时间序列模型拟合可以用程序 `3dNLfim` 完成：
   https://afni.nimh.nih.gov/pub/dist/doc/program_help/3dNLfim.html
* 时间序列输入的预处理可以用各种 AFNI 程序完成，
  或用“超级脚本” `afni_proc.py`：
   https://afni.nimh.nih.gov/pub/dist/doc/program_help/afni_proc.py.html

考虑时间序列模型： Z(t) = K(t)*S(t) + baseline + noise，
其中 Z(t) = 数据
      K(t) = 核（例如血流动力学响应函数或 HRF）
      S(t) = 刺激时间序列
  baseline = 常数、漂移等 [不感兴趣的回归量]
     以及 * = 卷积

那么 `3dDeconvolve` 在给定 S(t) 的情况下求解 K(t)。如果你想处理反问题，
在给定核 K(t) 的情况下求解 S(t)，请使用程序 `3dTfitter` 的 `-FALTUNG` 选项。
两种情况的区别在于：K(t) 被假定为因果的并且具有有限支撑，
而 S(t) 是全长的时间序列。注意，程序 `3dTfitter` 不具备
`3dDeconvolve` 计算输出统计量的全部能力；另一方面，`3dTfitter` 可以用
L1 或 L2 回归求解反卷积问题（两个方向都可以），并且可以对计算值施加符号约束
（例如要求输出 S(t) 或 K(t) 非负）：
 https://afni.nimh.nih.gov/pub/dist/doc/program_help/3dTfitter.html

一个更简单的反卷积：HRF -> IRF

  将持续刺激的 HRF 转换为脉冲的 IRF。

  0. 给定   HRF.1D : 响应可以过采样以看起来更漂亮
             TR     : （过采样的？）网格 TR
             sdur   : 刺激持续时间（以网格计数）
             idur   : 脉冲持续时间（以网格计数）

  1. 假装在 `sdur` 个时间点上有一个恒定刺激
     （并假装 TR=1s，不管实际 TR 是多少都可以）

        1deval -num $sdur -expr t > stim.1D

  2. 反卷积（适当插入 $sdur 和 $sdur-1）：

        3dDeconvolve -input HRF.1D\' -polort -1 -num_stimts 1      \
                     -stim_times 1 stim.1D 'TENT(0,$idur-1,$idur)' \
                     -x1D x.xmat.1D -bucket irf.1D

  3. 缩放到单位高度（设置 $MAX）：

        3dTstat -max -prefix - irf.1D\'
        # 并使用 MAX
        1deval -a irf.1D -expr a/$MAX > irf.scaled.1D

  4. 可能需要编辑端点（稍微截断）

        1dplot irf.scaled.1D

`3dDeconvolve`（以及 `3dREMLfit`）中的“基线模型”不仅仅意味着信号的常数（均值）水平，
甚至也不只是 FMRI 时间序列中发生的慢漂移。这里的“基线”还意味着形成零假设的模型。
`Full_Fstat` 结果是全模型（所有回归量）相对于基线模型的 F 统计量。因此，
通常会把不规则时间序列，例如估计的运动参数，通过 `-stim_file` / `-stim_base`
选项，或通过 `-ortvec` 选项（一次包含多个回归量）纳入基线模型。
因此，“基线模型”实际上是“零假设模型”。
------------------------------------------------------------------------
非常重要的一点是，要认识到 `3dDeconvolve` 中计算的统计量（F、t、R^2）是边际（或偏）统计量。
例如，单个 beta 系数的 t 统计量衡量该 beta 值相对于“只移除该矩阵列”的回归模型的显著性；
也就是说，该 t 统计量的零假设是“全回归模型减去仅这一个回归量”。
类似地，一组回归量的 F 统计量衡量这组回归量的显著性（例如一组 TENT 函数），
相对于“全模型仅移除这组回归量”的模型。如果这个解释或其后果不清楚，
你需要咨询统计学家，或者咨询 AFNI 留言板上的专家实体
（当他们能从 Taniquetil 山或 Kailash 峰顶被引诱下来时）。

AFNI 包中的回归程序：
* `3dDeconvolve` 的核心是求解线性回归问题 z = X b，
  给定每个体素中的数据向量 z，以及每个体素中相同的矩阵 X，求解参数向量 b。
  解按普通最小二乘（OLSQ）意义计算。
* 程序 `3dREMLfit` 做类似的事情，但允许数据中存在 ARMA(1,1) 序列相关，
  因此求解方法称为广义最小二乘（GLSQ）。
* 如果你想求解 X 中某些矩阵列（回归量）在不同体素中不同（空间可变）的问题，
  请使用程序 `3dTfitter`，它使用 OLSQ，或使用 `3dREMLfit`。
* `3dTfitter` 还可以使用 L1 和 LASSO 回归，而不是 OLSQ；如果你想使用这种“稳健”拟合方法，
  这个程序就是你的朋友。它还可以对参数 b 施加符号约束（正性或负性），
  并且（如上所述）可以做反卷积。
* `3dBandpass` 和 `3dTproject` 可以执行一系列“时间序列清理”操作，
  包括通过 OLSQ“回归掉”一组干扰向量（列）。
* `3dLSS` 可用于用另一种线性技术求解 `-stim_times_IM` 系统，
  该方法给出有偏结果，但方差更小。

用法细节：
3dDeconvolve command-line-arguments ...

**** 输入数据和控制选项 ****

-input fname         fname = 3D+时间 输入数据集的文件名
                       [可以给出多个文件名]
                       [这里，这些数据集会在时间上自动拼接；]
                       [如果这样做，就不需要 '-concat'，它会被忽略。]
                **** 你可以在这里输入一个 1D 时间序列文件，
                     但时间轴应沿行方向，而不是像 -input1D 选项
                     那样沿列方向。你可以在输入时通过在文件名末尾
                     使用 \' 运算符自动转置 1D 文件，例如：
                       -input fred.1D\'
                  ** 这是使用 3dDeconvolve 处理多列 1D 时间序列
                     文件的唯一方法。
                   * 输出数据集默认会采用 1D 格式。若要将它们格式化为
                     AFNI 数据集，请使用：
                       -DAFNI_WRITE_1D_AS_PREFIX=YES
                     放在命令行上。
                   * 如果你使用 '-input' 而不是 '-input1D'，
                     应使用 '-force_TR' 来设置 1D“数据集”的 TR
                     [默认是 1.0 秒]。

-sat OR -trans     * 3dDeconvolve 可以检查数据集时间序列的初始饱和瞬态，
                     这些通常应在数据分析前被切除。
                     （或者应被删失掉：见下面的 '-censor'。）
                     如果你想让它做这个有点耗时的检查，请使用选项 '-sat'。
                   * 或者将环境变量 AFNI_SKIP_SATCHECK 设为 NO。
                   * 程序 3dSatCheck 也可以做这个检查。

[-noblock]           通常，如果你用 '-input' 输入多个数据集，
                     那么这些分开的数据集会被视为独立的图像运行，
                     并分别获得独立的基线模型。如果你想让程序
                     把它们视为一个大运行，请使用 -noblock。
                   * 如果任何输入数据集只有 1 个子砖，则该选项会自动启用！
                   * 如果不使用自动拼接功能，那么这个选项无论如何都没有效果。

[-force_TR TR]       使用这个 TR 值，而不是 -input 数据集中的 TR。
                     （最好用 3drefit 修正输入。）

[-input1D dname]     dname = 单个（fMRI）.1D 时间序列文件名，
                             时间沿列向下。
                    * 如果你想分析 .1D 文件中的多列，
                      请参见上面的 '-input' 选项中的技术。

[-TR_1D tr1d]        tr1d = .1D 时间序列的 TR [默认 1.0 秒]。
                     没有 -input1D 时此选项无效。

[-nodata [NT [TR]]   仅评估实验设计（无输入数据）
                   * 可选，但强烈推荐：在 '-nodata' 后跟两个数字，
                     NT=时间点数，TR=点之间的时间间隔（秒）

[-mask mname]        mname = 3D 掩码数据集文件名
                      只分析掩码内的数据时间序列；掩码外体素的结果设为零。

[-automask]          从输入数据自动构建掩码
                      （对长时间序列数据集会很慢）
                  ** 如果你不指定任何掩码，程序会自动构建一个掩码
                     （基于每个体素的 RMS），并仅用于报告截断为 short 的错误
                     （如果使用 '-short'）以及计算 bucket 数据集头中的 FDR 曲线
                     （除非使用 '-noFDR'）。
                   * 如果你不想在这个自动生成的掩码内计算 FDR 曲线，
                     请使用 '-noFDR'，之后在 bucket 数据集上运行
                     '3drefit -addFDR'。
                   * 准确地说，上述默认掩码只在你使用 '-input'
                     以 3D+时间 数据集运行程序时发生；使用 '-input1D' 时不会。

[-STATmask sname]    从文件 'sname' 构建掩码，并用这个掩码
                       报告截断到浮点的问题以及计算 FDR 曲线。
                       实际结果不会用这个选项掩码（只使用 '-mask'
                       或 '-automask' 选项进行掩码）。
                       * 如果你不使用 '-STATmask'，那么 '-mask' 或
                         '-automask' 的掩码会用于这些目的。如果两者
                         都未给出，则使用上面刚描述的自动生成掩码。

[-censor cname]      cname = 删失 .1D 时间序列文件名
                   * 这是一个由 1 和 0 组成的文件，指示哪些时间点
                     应包含（1），哪些应排除（0）。
                   * 选项 '-censor' 只能使用一次！
                   * 下面的选项可能更容易使用！

[-CENSORTR clist]    clist = 指定要从分析中移除的时间索引的字符串列表。
                       每个字符串是以下形式之一：
                           37 => 移除全局时间索引 #37
                         2:37 => 移除运行 #2 中的时间索引 #37
                       37..47 => 移除全局时间索引 #37-47
                       37-47  => 同上
                     2:37..47 => 移除运行 #2 中的时间索引 #37-47
                     *:0-2    => 移除所有运行中的时间索引 #0-2
                      +每个运行内的时间索引从 0 开始。
                      +运行索引从 1 开始（就是为了让人困惑）。
                      +可以使用多个 -CENSORTR 选项，或一次给出多个
                        -CENSORTR 字符串，用空格或逗号分隔。
                      +注意：2:37,47 表示运行 #2 中的索引 #37 和
                        全局时间索引 47；它不表示运行 #2 中的索引 #37
                        以及运行 #2 中的索引 #47。

[-concat rname]      rname = 拼接运行列表的文件名
                      * 'rname' 可以是如下格式：
                          '1D: 0 100 200 300'
                        这表示 4 个运行，第一个从时间索引=0 开始，
                        第二个从索引=100 开始，依此类推。

[-nfirst fnum]       fnum = 在反卷积过程中使用的第一个数据集图像编号。
                       [默认 = max maxlag]

[-nlast  lnum]       lnum = 在反卷积过程中使用的最后一个数据集图像编号。
                       [默认 = 最后一点]

[-polort pnum]       pnum = 对应于零假设的多项式阶数 [默认：pnum = 1]
                    ** 对于 pnum > 2，这种基线去趋势大致相当于
                       高通滤波，截止频率为 (p-2)/D Hz，其中 'D' 是
                       成像运行持续时间：D = N*TR
                    ** 如果 pnum 使用 'A'，程序会根据最长运行的
                       持续时间 D 自动选择值：
                         pnum = 1 + int(D/150)
                ==>>** 3dDeconvolve 是唯一允许使用 'A' 自动设置
                       多项式阶数的带 -polort 选项的 AFNI 程序！！！
                    ** 使用 '-1' 表示特别不包含任何多项式到基线模型中。
                       只有在你明白这意味着什么时才这样做！

[-legendre]          对零假设（基线模型）使用勒让德多项式

[-nolegendre]        对零假设使用幂多项式
                       [默认是 -legendre]
                    ** 除非你疯了，否则不要这样做！

[-nodmbase]          不对基线时间序列去均值
                       （即 polort>0 和 -stim_base 输入）
[-dmbase]            对基线时间序列去均值 [polort>=0 时默认]

[-svd]               使用 SVD 而不是高斯消元 [默认]
[-nosvd]             使用高斯消元而不是 SVD
                       （仅用于测试和向后兼容）

[-rmsmin r]          r = 拒绝简化模型的最小 rms 误差
                       （默认 = 0；通常不要使用这个选项！）

[-nocond]            不计算矩阵条件数
                      ** 这个值与 Matlab 中的不同！

[-singvals]          打印矩阵奇异值
                      （对某些测试/调试目的有用）
                      另见程序 1dsvd。

[-GOFORIT [g]]       即使矩阵有严重问题（例如重复列、大条件数等），
                     也继续执行。
               *注意：你尤其应留意的警告文本中某处会有字符串 '!!'。
               *注意：错误和警告消息会发送到 stderr，也会写入文件
                      3dDeconvolve.err。
                      ++ 你可以在运行前将环境变量 AFNI_USE_ERROR_FILE
                         设为 NO 来禁用这个 .err 文件的创建。
               *注意：出现的可选数字 'g' 是可以忽略的警告数量。
                      也就是说，如果你使用 -GOFORIT 7，而出现了 9 个
                      '!!' 矩阵警告，那么程序不会运行。如果 'g' 不存在，
                      则使用 1。

[-allzero_OK]        不把全零矩阵列视为需要 -GOFORIT 才能忽略的错误类型。
                     * 使用这个选项时，请知道你在做什么！

[-Dname=val]        = 仅在本次程序运行中，将环境变量 'name' 设为 'val'。

               *注意：程序 1dBport 是生成用于 '-ortvec' 的文件的一个地方；
                      1deval 可能是另一个。

[-stim_maxlag k n]   n = 第 k 个输入刺激的最大时间延迟

[-stim_nptr k p]     p = 每个 TR 的刺激函数点数
                       注意：这个选项要求 0 切片偏移时间
                       [默认：p = 1]

** 刺激定时文件的一般规则（局部时间）：
   - 局部格式：N 行对应 N 个运行
   - 每一行包含该运行的所有事件
   - 事件起始时间是从该运行开始算起的秒数
   - 同一文件中的所有事件应一致使用调制器
     - 0 个或多个幅度调制器
     - 0 个或 1 个持续时间
   + 单个事件的一般格式
     - 简单格式（只有起始时间）
       - 起始时间（从运行开始）
     - 调制格式（幅度和/或持续时间调制）：
       - 起始时间
       - 然后（可选）*amp，对每个幅度调制器 amp
       - 然后（可选）:dur，如果包含事件持续时间
     + 单个事件的通用格式：
          onset*amp_A*amp_B...*amp_K:dur
   -----------------------------------------
   + 示例（2 个事件，仅 1 个运行）：
       13.6            27.9                 # 仅起始时间
       13.6*1.4        27.9*-0.13           # 起始时间和单个 AM 项
       13.6*1.4*-0.8   27.9*-0.13*-0.62     # 起始时间和 2 个 AM 项
       13.6:3.6        27.9:1.843           # 起始时间和持续时间
       13.6*1.4:3.6    27.9*-0.13:1.843     # 起始时间、AM、持续时间
   -----------------------------------------
   - 如果某个运行没有事件：
     - 为该运行使用 2 个事件占位符（2 表示局部定时）
     - 简单格式（仅起始时间）：为每个占位符使用 '*'
       - 空运行应看起来像：* *
     - 如果同时有调制器（包括适当的调制器）
       - 空运行应看起来像：-1*0:0
         （假设一个 AM 和一个 DM——匹配其他事件的格式）
   - 如果每个运行最多一个事件，则额外包含一个 '*' 以表示局部定时
   -----------------------------------------
   + 示例 1：简单格式，3 个运行，运行 2 中无事件
       13.6  27.9  46.13
       * *
       9.42  26.1  57.8
   + 示例 2：简单格式，3 个运行，稀有事件，想要局部时间
               - 要成为局部时间，至少一个运行中必须有至少 2 个事件
                 （仍然用 '*' 表示额外事件，仅在运行 1 或所有运行中）
       13.6  *
       * *
       9.42  *
   + 示例 3：包含一个幅度调制器
       13.6*0.3       27.9*-0.6      46.13*1.4
       -1*0           -1*0
       9.42*-0.9      26.1*-0.6      57.8*0.4
   + 示例 4：包含一个幅度调制器和一个持续时间
       13.6*0.3:1.4   27.9*-0.6:2.0  46.13*1.4:1.5
       -1*0:0         -1*0:0
       9.42*-0.9:1.7  26.1*-0.6:2.1  57.8*0.4:1.2

[-stim_times k tname Rmodel]
   根据文件 'tname' 中给出的一组刺激时间，生成第 k 个响应模型。
    *** 文件 'tname' 的格式是每个成像运行一行
        （参见上面的 '-concat'），每一行包含类别 'k' 在该对应运行中
        刺激的起始时间（秒）；时间相对于运行开始
        （即第 0 个子砖发生在 time=0）。
    *** 刺激的持续时间编码在下面的 'Rmodel' 参数中。
        单位是秒，不是 TR！
        -- 如果同一类别 'k' 中的不同刺激有不同持续时间，
           你必须使用 dmBLOCK 响应模型和 '-stim_times_AM1' 或
           '-stim_times_AM2'，见下文。
    *** 'tname' 文件中的不同行可以包含不同数量的起始时间。
        每一行必须至少包含 1 个时间。
    *** 如果类别 'k' 在某个成像运行中没有刺激，有两种表示方法：
          (a) 在该行放一个单独的 '*'，或
          (b) 放一个非常大的数或负数（例如 99999，或 -1）
              -- 超出成像运行范围的时间会产生警告消息，
                 但程序会继续执行。
    *** 如果刺激实际上不存在于数据模型中（例如 'tname' 中每一行都是 '*'），
        你还需要使用 '-allzero_OK' 选项，以强制 3dDeconvolve
        在回归矩阵列全为零的情况下运行。

   响应模型由 '-stim_times' 后的第三个参数（'Rmodel'）指定，
   可以是以下之一：
    *** 在下面的描述中，“1 参数”模型具有固定形状，
        只有估计幅度（'Coef'）变化：
          BLOCK GAM TWOGAM SPMG1 WAV MION
    *** 具有多于 1 个参数的模型有多个基函数，
        估计参数（'Coef'）是它们的幅度。估计的刺激响应形状
        在不同体素中会不同：
          TENT CSPLIN SPMG2 SPMG3 POLY SIN EXPR
    *** 许多模型需要输入响应的开始和停止时间，'b' 和 'c'。
        通常 'b' 应为零，但在某些情况下，'b' 可以为负——例如，
        如果你关心预期效应。停止时间 'c' 应基于你现实地期望
        血流动力学响应在刺激开始后持续多久；例如，刺激持续时间
        加上 BOLD 的 14 秒。
    *** 如果使用 '-tout'，每个参数会获得单独的 t 统计量。
        如上文所述，这是边际统计量，衡量该模型成分对回归拟合的影响，
        相对于移除该一个成分（矩阵列）后的拟合。
    *** 如果使用 '-fout'，每个刺激还会获得一个 F 统计量，
        这是它包含的所有模型成分的集体影响，相对于移除整个刺激后的回归拟合。
        （如果只有 1 个参数，则 F = t*t。）
    *** 下面一些模型被描述为：先有一个简单响应函数，
        然后与一个方波卷积，方波持续时间是你给出的参数
        （持续时间不是会被估计的参数）。请仔细阅读下面的描述：
        并非所有函数都（或都能）以这种方式卷积：
         * 总是卷积：      BLOCK  dmBLOCK  MION  MIONN
         * 可选卷积：      GAM    TWOGAM   SPMGx WAV
         * 从不卷积：      TENT   CSPLIN   POLY  SIN   EXPR
        卷积通过提供持续时间参数来指定，如下面每个特定模型函数所述。

     'BLOCK(d,p)'  = 1 参数块刺激，持续时间 'd'
                    ** BLOCK 有 2 个变体：
                         BLOCK4 [默认] 和 BLOCK5
                       它们有稍微不同的延迟：
                         HRF(t) = int( g(t-s) , s=0..min(t,d) )
                       其中 g(t) = t^q * exp(-t) /(q^q*exp(-q))
                       且 q = 4 或 5。q=5 的情况比 q=4 大约延迟 1 秒。
                ==> ** 尽管名字叫 BLOCK，你可以通过把持续时间设为小值，
                       将其用于事件相关分析；例如 'BLOCK5(1,1)'
                    ** 'p' 参数是基函数的幅度，通常应设为 1。
                       如果省略 'p'，幅度将取决于持续时间 'd'，
                       这仅在特殊情况下有用！！
                    ** 由于糟糕的历史原因，不带 'p' 参数的 BLOCK
                       峰值幅度在持续时间 'd' 变大时不会趋近 1。
                       纠正这个疏忽会破坏一些人的生活，所以就是这样。
                    ** 'UBLOCK' 函数（U 表示 Unit）与 'BLOCK' 函数相同，
                       不同之处在于当 'p' 参数缺失（或为 0）时，
                       峰值幅度在持续时间变大时趋近 1。
                       如果 p > 0，'UBLOCK(d,p)' 和 'BLOCK(d,p)' 相同。

     'TENT(b,c,n)' = 从刺激时间后 b..c 时间的 n 参数帐篷函数展开
                       [分段线性]
                       [n 必须至少为 2；时间步长为 (c-b)/(n-1)]
    'CSPLIN(b,c,n)'= 从刺激时间后 b..c 时间的 n 参数三次样条函数展开
                       [n 必须至少为 4]
                     ** CSPLIN 是 TENT 的升级替代，是一组可微函数。
                     ** TENT 和 CSPLIN 是“基数”插值函数：
                        它们的参数是 HRF 模型在 n 个“节点”点处的值：
                          b , b+dt , b+2*dt , ... [dt = (c-b)/(n-1)]
                        相比之下，在 POLY 或 SIN 等模型中，
                        输出参数并不直接是任何特定点的血流动力学响应函数值。
                 ==> ** 你也可以使用 'TENTzero' 和 'CSPLINzero'，
                        这意味着从每组中消除第一个和最后一个基函数。
                        这些省略的效果是强制反卷积出的 HRF 在 t=b 和 t=c
                        处为零（开始和结束响应为零）。使用这些“zero”
                        响应模型时，有 n-2 个参数（因此对于 'TENTzero'，
                        n 必须至少为 3）。
                     ** 这些“zero”函数会强制 HRF 连续，因为它们
                        将无法在 t=b 突然从 0 上升和/或在 t=c 突然下降到 0。

     'GAM(p,q)'    = 1 参数 gamma 变量
                         (t/(p*q))^p * exp(p-t/q)
                       如果只使用 'GAM'，默认值：p=8.6 q=0.547
                     ** 'GAM(p,q)' 的峰值在刺激后 p*q 时间处。
                        FWHM 约为 2.35*sqrt(p)*q；
                        这个近似对 p > 0.3*q 准确。
                     ** 要检查这个近似，试试命令：
               1deval -num 100 -del 0.02 -xzero 0.02   \
                      -expr 'sqrt(gamp(x,1))/2.35/x' | \
               1dplot -stdin -del 0.02 -xzero 0.02 -yaxis 1:1.4:4:10
                        如果两个函数 gamp(x,1) 和 2.35*x 相等，
                        图就会是常数 y=1。
                 ==> ** 如果你添加第三个参数 'd'，那么 GAM 函数会与
                        持续 'd' 秒的方波卷积；例如：
                          'GAM(8.6,.547,17)'
                        用于 17 秒刺激。[2010 年 8 月 9 日]
     'GAMpw(K,W)'  = 与 'GAM(p,q)' 相同，但形状参数指定为
                       峰值时间 'K' 和半高全宽（FWHM）'W'。
                       你也可以添加第三个参数作为持续时间。
                       (K,W) 参数会转换为 (p,q) 值用于实际计算；
                       (p,q) 参数会打印到文本（stderr）输出。
                     ** 注意，如果你给 K 和 W 奇怪的值，会发生奇怪的事情：
                        (tcsh 语法)
                         set pp = `ccalc 'gamp(2,8)'`
                         set qq = `ccalc 'gamq(2,8)'`
                         1deval -p=$pp -q=$qq -num 200 -del 0.1  \
                                -expr '(t/p/q)^p*exp(p-t/q)'   | \
                                1dplot -stdin -del 0.1
                        这里 K 明显小于 W，所以拟合峰值=2、宽度=8 的
                        gamma 变量形状一定很奇怪。[还要注意使用
                        'calc' 函数 gamp(K,W) 和 gamq(K,W) 在脚本中
                        从 K 和 W 计算 p 和 q。]

     'TWOGAM(p1,q1,r,p2,q2)'
                   = 1 参数（幅度）模型：
                   = 两个 'GAM' 函数的组合：
                         GAM(p1,q1) - r*GAM(p2,q2)
                       这个模型旨在让你使用类似于 BrainVoyager 的 HRF。
                       你可以添加第六个参数作为持续时间。
                     ** 注意，正的 'r' 参数意味着减去第二个 GAM 函数
                        （下冲）。
     'TWOGAMpw(K1,W1,r,K2,W2)'
                   = 同上，但给出两个 gamma 变量成分的峰值和宽度，
                       而不是不太直观的 p 和 q。
                       对 FMRI 工作，通常 K2 > K1，因为第二个（被减去的）
                       函数旨在建模模型主正部分之后的下冲。
                       你也可以添加第六个参数作为持续时间。
                     ** 示例（未给持续时间）：
        3dDeconvolve -num_stimts 1 -polort -1 -nodata 81 0.5         \
                     -stim_times 1 '1D: 0' 'TWOGAMpw(3,6,0.2,10,12)' \
                     -x1D stdout: | 1dplot -stdin -THICK -del 0.5

     'SPMG1'       = 1 参数 SPM gamma 变量基函数
                         exp(-t)*(A1*t^P1-A2*t^P2) 其中
                       A1 = 0.0083333333  P1 = 5  （主正波瓣）
                       A2 = 1.274527e-13  P2 = 15 （下冲部分）
                       这个函数没有归一化为峰值=1！
     'SPMG2'       = 2 参数 SPM：gamma 变量 + d/dt 导数
                       [为了向后兼容：'SPMG' == 'SPMG2']
     'SPMG3'       = 3 参数 SPM 基函数集
                 ==> ** SPMGx 函数现在可以接受一个可选（持续时间）参数，
                        指定原始 SPM 基函数应与一个持续 'duration' 秒的
                        方波卷积，然后归一化为峰值绝对值=1；
                        例如 'SPMG3(20)' 用于 20 秒持续时间、三个基函数。
                        [2009 年 4 月 28 日]
                     ** 注意 'SPMG1(0)' 会产生通常的 'SPMG1' 波函数形状，
                        但归一化为峰值=1（例如）。

     'POLY(b,c,n)' = 从刺激时间后 b..c 时间的 n 参数勒让德多项式展开
                       [n 范围从 1（常数）到 20]

     'SIN(b,c,n)'  = 从刺激时间后 b..c 时间的 n 参数正弦级数展开
                       [n 必须至少为 1]

     'WAV(d)'      = 1 参数块刺激，持续时间 'd'。
                      * 这是程序 waver 中的 '-WAV' 函数！
                      * 如果你希望设置 WAV 函数的形状参数，可以通过
                        添加额外参数来实现，顺序为：
                         延迟时间、上升时间、下降时间、
                         下冲比例、下冲恢复时间
                      * 默认值是 'WAV(d,2,4,6,0.2,2)'
                      * 省略的参数使用默认值。
                      * 'WAV(d,,,,0)'（设置下冲=0）与 'BLOCK5(d,1)' 非常相似，
                        当 d > 0 时。
                      * 将持续时间 d 设为 0（或只使用 'WAV'）会给出
                        来自 waver 的纯 '-WAV' 脉冲响应函数。
                      * 如果 d > 0，WAV(0) 函数会与持续 d 的方波卷积
                        以形成 HRF，幅度会缩放回 1。

     'EXPR(b,c) exp1 ... expn'
                   = n 参数；从刺激时间后 b..c 时间的任意表达式
                      * 表达式用空格分隔，所以每个表达式必须是
                        连续的非空白字符块
                      * 整个模型，从 'EXPR' 到最后一个表达式，
                        必须括在一组引号内。各个成分表达式用空格分隔。
                        示例：
                          '-EXPR(0,20) sin(PI*t/20)^2'
                      * 表达式使用与 3dcalc 相同的格式
                      * 表达式中可用的符号：
                         t = 从刺激时间起的秒数
                         x = 时间缩放为 x= 0..1，对应 t=bot..top
                         z = 时间缩放为 z=-1..1，对应 t=bot..top
                      * 不允许空间依赖的回归量！
                      * 其他符号会静默设为 0。
                 ==> ** 'EXPR' 函数不与方波进行任何隐含卷积。
                        你输入的表达式就是你在每个刺激时间后 b..c 时间内
                        得到的结果。为了确定你的响应模型是什么，
                        你应该绘制矩阵 .xmat.1D 输出文件中的相关列。

     'MION(d)'     = 1 参数块刺激，持续时间 'd'，
                     旨在建模 MION 的响应。
                     零持续时间脉冲响应 'MION(0)' 是：
                       h(t) = 16.4486 * ( -0.184/ 1.5 * exp(-t/ 1.5)
                                          +0.330/ 4.5 * exp(-t/ 4.5)
                                          +0.670/13.5 * exp(-t/13.5) )
                     改编自论文：
                      FP Leite, et al. NeuroImage 16:283-294 (2002)
                      http://dx.doi.org/10.1006/nimg.2002.1110
                  ** 注意这是一个正函数，但 MION 对激活产生负响应，
                     所以 MION 的 beta 和 t 统计量通常是负的。
               ***** 如果你想要负的 MION 函数（这样你会得到正的 beta），
                     请改用名称 'MIONN'。
                  ** 与持续 'd' 秒的方波卷积后，得到的单试次波形
                     被缩放到幅度 1。例如，试试这个有趣的命令来比较
                     BLOCK 和 MION：
               3dDeconvolve -nodata 300 1 -polort -1 -num_stimts 2   \
                            -stim_times 1 '1D: 10 150' 'MION(70)'    \
                            -stim_times 2 '1D: 10 150' 'BLOCK(70,1)' \
                            -x1D stdout: | 1dplot -stdin -one -thick
                     你会看到 MION 曲线比 BLOCK 曲线上升和下降慢得多。
              ==> ** 注意 'MION(d)' 已经与持续 'd' 秒的方波卷积。
                     不要再通过放入多个紧密间隔的刺激时间把它再次卷积
                     （这个错误曾经发生过）！
                  ** 将单试次波形缩放到幅度 1 意味着不同持续时间 'd'
                     的试次，其回归模型会有相同的幅度。

 * 3dDeconvolve 做线性回归，所以模型参数是基函数的幅度；
   1 参数模型是“简单”回归，其中脉冲响应函数的形状固定，
   只有幅度/大小变化。具有更多自由参数的模型有“可变”形状的
   脉冲响应函数。

 * 线性回归意味着每个数据时间序列（可视为一列数字 = 一个向量）
   被拟合为矩阵列的和，每一列乘以一个待计算的幅度参数（'Coef'）。
   各种选项
     '-stim_times'、'-polort'、'-ortvec' 和/或 '-stim_file'
   的目的就是构建回归矩阵的列。

 * 如果你想要非线性回归，见程序 3dNLfim。

 * 如果你想要允许非白噪声的线性回归，请在使用 3dDeconvolve
   建立回归模型（以矩阵文件形式）后，使用程序 3dREMLfit。

** 当你对所求响应模型的形状有任何疑问时， **
*  你应该绘制 X 矩阵中的相关列，以帮助理解分析。       *
*  上面的 'MION' 示例可以作为快速设置命令管道来绘制响应模型的起点。 *
*  在那个示例中，使用 '-polort -1' 来抑制通常的基线模型，因为绘制 *
*  矩阵的那部分只会让人困惑。另一个例子，比如比较类似模型       *
** 'WAV(10)'、'BLOCK4(10,1)' 和 'SPMG1(10)'：                 **

     3dDeconvolve -nodata 100 1.0 -num_stimts 3 -polort -1   \
                  -local_times -x1D stdout:                  \
                  -stim_times 1 '1D: 10 60' 'WAV(10)'        \
                  -stim_times 2 '1D: 10 60' 'BLOCK4(10,1)'   \
                  -stim_times 3 '1D: 10 60' 'SPMG1(10)'      \
      | 1dplot -thick -one -stdin -xlabel Time -ynames WAV BLOCK4 SPMG1

 * 关于 'tname' 文件的格式，请参见以下文档的最后部分：
 https://afni.nimh.nih.gov/pub/dist/doc/misc/Decon/DeconSummer2004.html
   并参见以下目录中存储的其他文档：
 https://afni.nimh.nih.gov/pub/dist/doc/misc/Decon/
   并阅读以下演示：
 https://afni.nimh.nih.gov/pub/dist/edu/latest/afni_handouts/afni05_regression.pdf
  ** 特别注意：
   * 'tname' 文件的内容不只是 0 和 1，而是刺激事件的实际时间（秒）。
   * 你可以用如下形式的字符串在命令行给出时间：
     '1D: 3.2 7.9 | 8.2 16.2 23.7' 来代替 'tname'，
     其中 '|' 字符表示新一行的开始
     （所以这个例子用于有 2 个拼接运行的情况）。
=> * 你不能对下面任何更复杂的 '-stim_times_*' 选项使用 '1D:' 形式输入！！
   * '1D:' 形式输入主要用于快速测试，如上面例子，而不是用于
     具有大量不同刺激时间和多个成像运行的生产分析。

[-stim_times_AM1 k tname Rmodel]
   类似，但生成幅度调制响应模型。
   'tname' 文件应由 'time*amplitude' 对组成。
   与 '-stim_times' 一样，当某个成像运行没有给定类别的刺激时，
   可以使用 '*' 字符作为占位符。
   *注意：我所说的“幅度”调制，在某些其他程序中称为“参数”调制。
 ***注意：如果所有运行都没有给定类别的刺激，那么你必须至少有 1 个
          不是 '*' 的时间，-stim_times_* 才能工作（以便设置正确数量的回归量）。
          为此你可以使用负时间，这会产生警告消息，但除此之外会被忽略，例如：
             -1*37
             *
          用于一个 2 运行的 'tname' 文件，与 -stim_times_* 一起使用。
       ** 在这种情况下，你还需要 -allzero_OK 选项，可能还需要 -GOFORIT。
    ** 可以将 '-stim_times_AM1' 与 Rmodel 为 TENT 结合使用。
       如果你在每个 TR 都有一个幅度参数，并且想尝试反卷积其对数据的影响，
       可以尝试以下步骤：
         a) 创建一个 1D 列文件，包含幅度参数，每个 TR 一个值，
            长度与数据匹配；假设这个文件叫 Akk.1D
         b) 创建一个 1D 列文件，包含每一行的实际 TR 时间；
            例如，如果你有 150 个时间点且 TR=2 s，那么
              1deval -num 150 -expr '2*i' > Att.1D
         c) 将这些文件粘合在一起，用于 -stim_times_AM1：
              echo `1dMarry Att.1D Akk.1D` > Atk.1D
         d) 使用选项
              -stim_times 1 Atk.1D 'TENT(0,20,11)' -stim_label 1 TENT
            这会给出持续 20 秒、有 11 个参数的 TENT 响应
            —— 每个 TR 一个。
         e) 使用你需要的所有其他巧妙选项，例如删失、基线、运动参数等。
       这里选择的选项可以变化，以约束反卷积；例如，使用 CSPLIN 而不是 TENT，
       或 CSPLINzero；在 TENT/CSPLIN 中使用更少参数以强制更平滑的反卷积等。
       绘制回归矩阵在这种分析中很有用，可以确保你得到想要的分析；
       例如：
         1dplot -sep_scl prefix.xmat.1D

[-stim_times_AM2 k tname Rmodel]
   类似，但生成 2 个响应模型：一个使用平均幅度，一个使用与平均值的差异。
  *** 请注意，'AM2' 可能是你应该使用的选项！
  *** 'AM1' 用于特殊情况，通常不应用于 FMRI 任务激活分析！！
  *** 'AM2' 将让你能够检测那些激活但不随幅度因子比例变化的体素，
      并提供激活与输入幅度因子变化比例性的直接测量。
      'AM1' 两者都做不到。
  *** 通常，3dDeconvolve 会从调制回归量中移除辅助参数的均值。
      但是，如果你将环境变量 AFNI_3dDeconvolve_rawAM2 设为 YES，
      则不会从辅助参数中移除均值。
      这个功能是提供给想用自己的方法中心化参数的用户。
  *** [2012 年 7 月 12 日] 你现在可以指定从每个调制参数中减去的值——
      这个值将替代通常发生的平均参数值减法。
      为此，在选项后添加一个额外参数，例如：
        -stim_times_AM2 1 timesAM.1D 'BLOCK(2,1)' :5.2:x:2.0
      额外参数必须以冒号 ':' 字符开头，并且应该有多少个不同的值
      （用 ':' 分隔）就有多少个参数在定时文件（上面的 timesAM.1D）中。
  ==> 在上面的例子中，':5.2:x:2.0' 意味着
        从 timesAM.1D 中第一个参数的每个值减去 5.2
        从第二个参数的每个值减去均值
          （因为 'x' 不转换为数字）
        从第三个参数的每个值减去 2.0
  ==> 这个选项到底有什么用？目的是方便对一组受试者的结果进行组分析，
      你希望以完全相同的方式处理每个受试者的分析——因此，
      某个参数（例如反应时间）的减法值应该是所有受试者所有试次中
      该参数的总均值。

 **************** 关于 dmBLOCK 的进一步说明 [2013 年 11 月] ****************

 基本上（在我看来），有 2 个合理选择：

   (a) 'dmUBLOCK' = 允许响应模型的幅度随刺激持续时间变化；
                    持续时间越大，幅度越大；对于超过约 15 秒的持续时间，
                    幅度将变为 1。
               -->> 这个选择等价于 'dmUBLOCK(0)'，但由于上面提到的
                    历史缩放问题，并不等价于 'dmBLOCK(0)'。

   (b) 'dmUBLOCK(1)' = 所有响应模型都会获得幅度 1，
                       无论刺激持续时间如何。
                  -->> 这个选择等价于 'dmBLOCK(1)'。

 一些用户表达了希望允许幅度随持续时间变化，如情况 (a)，但要指定
 幅度变为 1 的持续时间。这个愿望现在已经实现，提供以下情况：

   (a1) 'dmUBLOCK(-X)' = 将持续时间为 'X' 秒时的幅度设为 1；
                         例如，'dmBLOCK(-5)' 意味着持续时间为 5 的刺激
                         获得幅度 1，更短持续时间获得小于 1 的幅度，
                         更长持续时间获得大于 1 的幅度。
                    -->> 请注意 'dmBLOCK(-X)' 与情况 (a1) 不同，
                         实际上它没有意义。

 我希望这能澄清事情，让你的生活更简单、更快乐、更无忧。
 （如果不能，请责怪 Gang Chen，不要怪我。）

 一个例子，澄清这些情况之间的差异：
    3dDeconvolve -nodata 350 1 -polort -1 -num_stimts 3 \
                 -stim_times_AM1 1 q.1D 'dmUBLOCK'      \
                 -stim_times_AM1 2 q.1D 'dmUBLOCK(1)'   \
                 -stim_times_AM1 3 q.1D 'dmUBLOCK(-4)'  \
                 -x1D stdout: |                         \
     1dplot -stdin -thick                               \
            -ynames 'dmUBLOCK' 'dmUB(1)' 'dmUB(-4)'
 其中文件 q.1D 包含单行：
   10:1 60:2 110:4 160:10 210:20 260:30
 注意 'dmUBLOCK(-4)' 曲线（绿色）在第 3 个刺激处峰值为 1，
 对于后面（更长）的块峰值更大。
 而 'dmUBLOCK' 曲线（黑色）只在最长的块处峰值为 1，
 'dmUBLOCK(1)' 曲线（红色）对所有块峰值都为 1。

[-stim_times_FSL k tname Rmodel]
   这个选项允许你输入 FSL 风格的 3 列定时文件，
   其中每一行对应一个刺激事件/块；
   行 '40 20 1' 表示“刺激从 40 秒开始，持续 20 秒，幅度为 1”。
   由于在这个格式中，每个刺激可以有不同的持续时间并获得不同的响应幅度，
   所以 'Rmodel' 必须是上面的 'dm' 持续时间调制选项之一
   ['dmUBLOCK(1)' 可能最有用]。幅度调制被视为类似
   '-stim_times_AM1'，其中 'tname' 文件中给定的幅度乘以基本响应形状。
 *** 我们不提倡使用这个 '_FSL' 选项，但它是为了让一些（不幸的）人
     更容易编写脚本。
 *** 不能期望 3dDeconvolve（或 3dREMLfit）的结果与 FSL FEAT 完全相同，
     因为响应模型形状不同，以及许多其他细节不同。
 *** 你也可以使用 '-stim_times_FS1'，表示 'tname' 文件中的幅度因子
     应被忽略并全部替换为 '1'。
 *** FSL FEAT 只分析连续时间序列——在 FSL 中不可能像 '-concat'
     那样允许存在多个 EPI 运行（据我所知）。所以 FSL 刺激时间格式
     不允许这种可能性。在 3dDeconvolve 中，你可以通过使用一行
     由 '* * *' 组成来指示运行之间的中断，如下例：
         1 2 3
         4 5 6
         * * *
         7 8 9
     这表示 2 个运行，第一个有 2 个刺激，第二个只有 1 个刺激。
     如果有一个运行没有这种刺激的副本，那么你会连续使用两行 '* * *'。
     当然，使用 '* * *' 结构的文件不会与 FSL 兼容！

[-stim_times_IM k tname Rmodel]
   类似，但 'tname' 中的每个单独时间都会获得单独的回归量；
   'IM' 表示“单独调制”（Individually Modulated）——也就是说，
   每个事件都会有自己的幅度估计。想必你会收集这些许多幅度，
   然后对其做某种统计或分析。
 *注意：'tname' 文件中的每个时间都会获得单独的回归量。
        如果某些时间超出成像运行持续时间，或者该时间的响应模型
        只命中被删失掉的数据值，那么对应回归量将全为零。
        通常，如果矩阵有任何全零列，3dDeconvolve 不会运行。
        要进行分析，请使用 '-allzero_OK' 选项。全零列的幅度估计
        将为零，并且应从任何后续分析中排除。
        （可能你应该修正 'tname' 文件中的时间，而不是使用 '-allzero_OK'。）

[-global_times]
[-local_times]
   默认情况下，3dDeconvolve 会猜测各种 '-stim_times' 选项的 'tname'
   文件中的时间是全局时间（相对于运行 #1 开始）还是局部时间
   （相对于每个运行开始）。使用这些选项之一，你可以强制
   '-local_times' 或 '-global_times' 之后的 '-stim_times' 选项
   的时间被视为全局或局部。
 ** 使用这些选项之一（最常用的是 '-local_times'）非常推荐。

[-stim_times_millisec]
 这个选项会将任何 '-stim_times_*' 选项中的所有时间乘以 0.001；
 目的是允许你以毫秒而不是秒输入时间。这个因子将应用于所有
 '-stim_times' 输入，无论此选项在命令行上之前还是之后。
 这个因子会在 -stim_times_subtract 之前应用，所以减法值
 （如果存在）必须以秒为单位给出，而不是毫秒！

[-stim_times_subtract SS]
 这个选项意味着从任何 '-stim_times*' 选项中遇到的每个时间减去 'SS' 秒。
 这个选项的目的是让你可以简单地为每个成像运行开始处移除图像
 而调整定时文件。注意，这个选项只有在以下两个条件都成立时才有用：
  (a) 每个成像运行移除的图像数量完全相同
  (b) 'tname' 文件中的时间尚未针对这些图像移除进行调整
      （即时间指的是采集时的图像运行，而不是输入到 3dDeconvolve 的运行）。
 换句话说，请理解并谨慎使用这个选项！
 ** 注意，减去 'SS' 适用于所有 '-stim_times' 输入，无论此选项
    在命令行上之前还是之后！
 ** 并且它同样适用于全局时间和局部时间！
 ** 任何（如此减后）低于 0 的时间将被忽略，因为它落在成像运行开始之前。
 ** 这个选项和上一个选项只是为了方便，帮助你从任何来源设置
    '-stim_times*' 定时文件。

[-basis_normall a]
   将所有 '-stim_times' 的基函数归一化为幅度 'a'（必须 a > 0）。

    * -basis_normall 只影响命令行上出现在它后面的 -stim_times 选项
    * 这个选项主要用于 'EXPR' 基函数。

[-x1D_regcensored f] 将 X 矩阵保存为 .xmat.1D 文件，并通过添加 0-1 列
                     来施加删失，而不是切除被删失的行。
[-x1D_stop]          在写入 .xmat.1D 文件后停止运行。
                     * 用于测试，或者如果你要改为运行 3dREMLfit——
                       也就是说，你只是用 3dDeconvolve 设置矩阵文件。
[-progress n]        每第 n 个体素写入统计结果
                     * 让你知道有事情正在发生！

[-help]              哦，来吧，试试它！

**** 多 CPU 选项（仅本地 CPU，无网络） ****

 -jobs J   使用 'J' 个作业（子进程）运行程序。
             在多 CPU 机器上，这可以显著加快程序速度。
             在单 CPU 机器上，使用这个选项会很傻。
         * J 应该是一个从 1 到系统共享内存的 CPU 数量的数字。
         * J=1 是正常（单进程）操作。
         * J 允许的最大值是 32。
         * 与其他并行化的 AFNI 程序不同，这个程序不使用 OpenMP；
             它直接使用 fork() 和共享内存来运行多个进程。
         * 关于并行化的更多信息，见：
           https://afni.nimh.nih.gov/afni/doc/misc/afni_parallelize
         * 也使用 -mask 或 -automask 来获得更多速度；参见 3dAutomask。

-virtvec   为节省内存，将输入数据集写入临时文件，然后只在需要时
           从中读取数据向量。这个选项是为 Javier 准备的，可能对其他人没用。
           并且只有在 -jobs 大于 1 时才生效。
